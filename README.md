# Лабораторна робота №1 — варіант 1 (індивідуально)
Чисельне інтегрування: метод Сімпсона та метод трапецій. Один виконавець реалізує обидва алгоритми.

## Збирання
```sh
cmake -S . -B build
cmake --build build --config Release
```
Linux: `./build/Lab1App`; Visual Studio: `./build/Release/Lab1App.exe` (залежить від генератора).

## Git (індивідуальна імітація командного процесу)
Створіть гілки `feature/student-a` і `feature/student-b`, реалізуйте алгоритми та об'єднайте у `main`. Всі коміти належать одному виконавцю. Для демонстрації конфлікту змініть однаковий рядок main.cpp в обох гілках перед злиттям.
